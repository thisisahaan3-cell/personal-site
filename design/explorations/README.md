# Explorations

Static reference boards for the creative director. Nothing here is production code and no direction is final.

Capture: `node design/explorations/capture.mjs design/explorations/<board>.html` renders at 1440x900 to `shots/<board>.png` and prints which fonts loaded and whether anything overflows.
